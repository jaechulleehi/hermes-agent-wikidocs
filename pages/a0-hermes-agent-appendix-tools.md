## 부록 A. Hermes Agent 실전 운영 도구

부록은 본문을 다시 길게 설명하기 위한 장이 아니다. 책을 읽은 뒤 실제로 Hermes Agent를 세팅하거나 팀에 적용할 때 다시 꺼내 쓰는 참조 도구다.

본문이 “왜 이렇게 운영해야 하는가”를 설명한다면, 부록은 “지금 바로 무엇을 확인하고 적어야 하는가”를 정리한다. 처음부터 완벽하게 채울 필요는 없다. 운영하면서 기준이 생길 때마다 용어, 보안 항목, AI 팀 설계 내용을 업데이트하면 된다.

## 부록을 쓰는 순서

| 순서 | 부록 | 쓸 때 |
|---|---|---|
| A-1 | Hermes Agent 용어집 | memory, Skill, MCP, gateway, cron 같은 용어가 헷갈릴 때 |
| A-2 | Hermes Agent 보안 체크리스트 | Slack/gateway/cron/MCP/GitHub/WikiDocs 연결 전에 |
| A-3 | 나만의 AI 팀 설계 워크시트 | 메인 창구와 역할형 에이전트 구조를 실제 업무에 맞출 때 |

## 부록을 읽는 기준

용어집은 외우기 위한 페이지가 아니라 대화 기준을 맞추기 위한 페이지다. 보안 체크리스트는 모든 위험을 없애기보다, 자동화가 실제 상태를 바꾸기 전에 확인해야 할 최소 기준을 잡는 페이지다. AI 팀 설계 워크시트는 에이전트 이름을 늘리는 페이지가 아니라, 요청/역할/기억/도구/검증을 하나의 흐름으로 정리하는 페이지다.

부록까지 채우고 나면 이 책의 결과물은 단순한 지식이 아니라 운영 문서가 된다. “무엇을 기억할지, 무엇을 Skill로 남길지, 어떤 도구를 연결할지, 어떤 기준으로 공개할지”를 스스로 점검할 수 있어야 한다.
