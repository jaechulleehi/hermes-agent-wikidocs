# 에르메스 에이전트 Ops(Hermes Agent Ops): AI 에이전트 운영 시스템과 MCP 자동화

Hermes Agent를 단순 챗봇이나 설치형 AI 도구가 아니라 **실제 업무 운영 시스템**으로 설계하고 굴리는 방법을 정리한 책입니다.

이 책은 기존의 Hermes Agent 입문·설치 가이드와 달리, 에이전트를 실제 팀 운영에 붙이면서 생기는 문제를 중심으로 다룹니다. 하비·방울이·뽀동이처럼 역할을 나눈 멀티 에이전트 운영, 메모리와 세션 경계, MCP 자동화, Slack/Google Workspace 연동, 운영 체크리스트, 복구 플레이북, 위키에서 강의와 콘텐츠로 이어지는 파이프라인까지 실제 시행착오를 바탕으로 설명합니다.

## 이 책의 차별점

- Hermes Agent의 기능 소개보다 **운영 구조와 판단 기준**에 집중합니다.
- 설치법보다 **도입 후 어디서 막히고 어떻게 복구하는지**를 다룹니다.
- 단일 AI 비서보다 **하비·방울이·뽀동이식 역할 분리 운영**을 설명합니다.
- MCP를 단순 연결 기능이 아니라 **업무 자동화 인터페이스**로 봅니다.
- 긴 대화, 메모리, 세션, 스킬, 프로필이 섞일 때 생기는 혼선을 운영 관점에서 정리합니다.
- 운영 기록을 위키, WikiDocs, 강의, 체크리스트로 재사용하는 콘텐츠 시스템까지 다룹니다.

## 이 책에서 다루는 것

- AI 에이전트 운영 시스템 설계
- Hermes Agent Ops 관점의 운영 철학
- 멀티 에이전트 역할 분리와 메인 창구 구조
- 세션, 메모리, 스킬, 프로필 경계
- MCP 자동화와 외부 도구 연동
- Slack, Google Workspace, Obsidian 기반 업무 흐름
- 운영 체크리스트와 복구 플레이북
- 위키, WikiDocs, 강의로 이어지는 콘텐츠 시스템

## 추천 독자

- Hermes Agent를 설치해보는 단계를 넘어 실제 업무에 붙이고 싶은 사람
- AI 에이전트를 개인 비서가 아니라 팀 운영 시스템으로 쓰고 싶은 사람
- Claude Code, Codex, Cursor, MCP 기반 자동화를 업무 흐름에 붙이고 싶은 사람
- 에이전트 도입 후 기억, 역할, 도구, 기록 관리에서 자주 막히는 사람
- AI 에이전트 운영, MCP 자동화, 멀티 에이전트 시스템을 한국어 사례로 이해하고 싶은 사람
