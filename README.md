# 에르메스 에이전트(Hermes Agent) 업무 자동화: 나만의 AI 팀 만들기

> AI 개인비서와 역할형 에이전트로 만드는 실전 업무 워크플로우

에르메스 에이전트(Hermes Agent)를 기반으로 **업무 자동화와 나만의 AI 팀**을 실제로 만들고 운영한 기록입니다.

이 책은 Hermes Agent의 설치법이나 기능 목록을 다시 설명하는 책이 아닙니다. AI 개인비서를 메인 창구로 두고, 조사/정리/실행처럼 역할이 나뉜 에이전트들과 함께 일하는 업무 자동화 흐름을 정리합니다. 긴 대화가 쌓일 때 기억이 흐려지는 문제, 누가 어떤 일을 맡아야 하는지의 역할 경계, Slack/Obsidian/Google Workspace/WikiDocs로 이어지는 작업 흐름, 반복 작업을 체크리스트와 위키로 남기는 방식까지 실제 운영 경험을 중심으로 다룹니다.

## 이 책의 차별점

- Hermes Agent의 기능 소개보다 **AI 업무 자동화가 실제로 굴러가는 운영 시스템**에 집중합니다.
- 설치법보다 **AI 개인비서와 역할형 에이전트들이 어떻게 일을 나눠 맡는지**를 다룹니다.
- 단일 챗봇이 아니라 **AI 개인비서 + 역할형 에이전트 팀** 구조를 설명합니다.
- MCP는 전면 주제가 아니라, 필요한 도구를 붙이는 **업무 연결 수단**으로 다룹니다.
- 메모리, 세션, 스킬, 프로필이 섞일 때 생기는 혼선을 실제 사용자의 관점에서 정리합니다.
- 대화, 조사, 정리, 문서화, 발행까지 이어지는 **AI 개인비서 워크플로우 실전 기록**을 보여줍니다.

## 이 책의 AI 팀 구성

이 책에서는 공개 개념을 먼저 설명하고, 실제 운영 사례로 하비, 방울이, 뽀동이, 봉구, 비벙이, 하망이 같은 이름을 소개합니다. 이 이름들은 캐릭터 설정이 아니라 역할형 에이전트를 실무에서 부르기 쉽게 만든 운영 이름입니다.

| 공개 개념 | 운영 사례 이름 | 주 역할 |
|---|---|---|
| AI 개인비서 / 메인 창구 | 하비 | 요청 해석, 위임, 최종 통합 |
| 조사형 에이전트 | 방울이 | 탐색, 근거 수집, 비교 |
| 정리형 에이전트 | 뽀동이 | 문서화, 구조화, 보고서/글 정리 |
| 실행형 에이전트 | 봉구 | 파일 수정, 명령 실행, 검증 |
| 제품/기능 정리형 | 비벙이 | 요구사항, 기능 흐름, 제품 문서화 |
| 이미지 제작형 | 하망이 | 썸네일, 설명 이미지, 시각 콘셉트 제작 |

## 이 책에서 다루는 것

- 에르메스 에이전트(Hermes Agent) 기반 업무 자동화
- 챗봇이 아니라 나만의 AI 팀을 만드는 방식
- AI 개인비서 중심의 메인 창구 운영
- 조사형/정리형/실행형 역할 에이전트 운영
- 조사, 정리, 실행, 기록으로 이어지는 AI 업무 자동화 워크플로우
- 세션, 메모리, 스킬, 프로필 경계
- Slack, Obsidian, Google Workspace, WikiDocs 기반 업무 흐름
- MCP와 외부 도구를 필요한 순간에 붙이는 방식
- 체크리스트와 복구 플레이북
- 위키, WikiDocs, 강의로 이어지는 콘텐츠 시스템

## 추천 독자

- AI를 단순 챗봇이 아니라 개인비서처럼 쓰고 싶은 사람
- 업무 자동화에 AI 에이전트를 실제로 붙여보고 싶은 사람
- Claude Code, Codex, Cursor, Hermes Agent, MCP를 업무 흐름 안에서 써보고 싶은 사람
- 조사, 정리, 문서화, 발행을 AI와 함께 반복 가능한 워크플로우로 만들고 싶은 사람
- 혼자 일하지만 여러 역할의 AI 팀을 두고 일하는 방식을 만들고 싶은 사람
