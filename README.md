# 에르메스 에이전트(Hermes Agent) 운영 입문

AI 에이전트를 단순 챗봇이 아니라 **실제 업무 시스템**으로 운영하기 위한 구축·운영 기록입니다.

이 책은 에르메스 에이전트(Hermes Agent)를 도입하고 운영하면서 정리한 실전 가이드입니다. OpenClaw에서 Hermes로 전환한 이유, 하비·방울이·뽀동이처럼 역할을 나눈 멀티 에이전트 운영, 메모리와 세션 관리, MCP와 외부 도구 연동, 장애 복구 체크리스트, 콘텐츠 파이프라인까지 실제 시행착오를 바탕으로 설명합니다.

## 이 책에서 다루는 것

- AI 에이전트 운영 시스템 설계
- Hermes Agent 기본 운영 철학
- 멀티 에이전트 역할 분리와 메인 창구 구조
- 세션, 메모리, 스킬, 프로필 경계
- MCP, Slack, Google Workspace 등 외부 도구 연동
- 운영 체크리스트와 복구 플레이북
- 위키, 블로그, 강의로 이어지는 콘텐츠 시스템

## 추천 독자

- AI 에이전트를 개인 비서가 아니라 팀 운영 시스템으로 쓰고 싶은 사람
- Claude Code, Codex, Cursor, MCP 기반 자동화를 업무에 붙이고 싶은 사람
- 에이전트 도입 후 기억, 역할, 도구, 기록 관리에서 자주 막히는 사람
- 에르메스 에이전트(Hermes Agent)를 한국어로 이해하고 싶은 사람
